# Contributing

I keep this repository as a record of notes I have written as a CU student. Contributions are welcome when they improve or add to the modified notes and self-study notes.

I accept contributions only to:

- **MOD** documents: more organised versions of original class notes.
- **SS** documents: notes written independently of classes and lectures.

I do not accept contributions to **OD** documents. They are my original record of what was written and taken in class.

## Before opening a pull request

Create a GitHub issue first. Describe the course, the document you want to change or add, and what you propose to do. An issue gives us a place to discuss the change before a pull request is opened.

## Making a contribution

1. Check that the document is a MOD or SS, not an OD.
2. Keep the filename in this format: `COURSECODE-DD-MM-YYYY-TYPE.md`.
3. Keep the notes clear, organised, and consistent with the existing Markdown files.
4. For SS notes, include links or references for material that comes from outside the repository.
5. Open a pull request after creating the issue, and link the issue in the pull request description.

Please keep a pull request focused on the change described in its issue.
