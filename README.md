# Notes

These are notes I have written as a Covenant University (CU) student in 200 level.

I keep the original notes taken in class separate from the versions I have reorganised and the notes I have written independently. That way, it is clear what came from class, what I later revised, and what I studied on my own.

## How the notes are organised

Each note is a Markdown file named using this format:

`COURSECODE-DD-MM-YYYY-TYPE.md`

- `COURSECODE` is the course code.
- `DD-MM-YYYY` is the date associated with the notes.
- `TYPE` describes how the notes were written.

There are three types:

- **OD (Original Document):** The original document and notes taken right in class.
- **MOD (Modified):** A more organised version of an OD document.
- **SS (Self Study):** Notes I wrote independently of classes and lectures.

For example:

```text
SEN211-26-10-2026-MOD.md
```

The type matters. A MOD is not the original class document, and an SS document is not presented as lecture notes.
